# مساحتي — Masahati

مكتبة شخصية عربية تعمل كتطبيق على الهاتف والحاسوب: ملفات PDF وصوتيات ومرئيات ويوتيوب وتيليجرام، فوائد وتظليل، جدول ومهام وأوقات صلاة، اقتباسات وبطاقات وخرائط ذهنية. كل البيانات تُحفظ في متصفح الجهاز — لا خادم ولا حساب.

## البنية

| المسار | الوصف |
|---|---|
| `site/` | الموقع الجاهز للرفع (هذا ما يُنشر) |
| `site/api/tg.php` | وسيط تيليجرام — يعمل على أي استضافة PHP مثل Hostinger |
| `_src/masahati/` | النسخة الأصلية قبل التعديل |
| `_src/patch.py` + `_src/extra.css` | يبنيان `site/index.html` من الأصل: `python3 _src/patch.py` |

## النشر

- **Hostinger (موصى به):** ارفع محتويات `site/` إلى `public_html`. التفاصيل في `site/اقرأني-الرفع.txt`.
  أو من hPanel ← Advanced ← Git: اربط هذا المستودع وحدّد المجلد `site`.
- **GitHub Pages:** يُنشر تلقائيًا من `site/` عند كل دفعة إلى `main` (بلا وسيط PHP — يستعمل وسطاء عامّة لتيليجرام).

عند كل إصدار جديد غيّر `VER` في `site/sw.js` و`APP_VER` في `_src/patch.py`.
